# private-manim

Bits of Chris explainer videos in Manim: 9:16 Shorts (45–60 s, voice
recorded once, every visual generated by agents) and 16:9 explainer scenes.

- Agents and contributors start at `AGENTS.md`.
- The Shorts process is `agents/runbook.md`.
- Each video lives in `videos/NNN-slug/` with its storyboard, voice, scenes
  and publish copy. Rendered output is gitignored (`media/`).

```
uv run --no-sync python -m unittest discover -s tests   # tests
```

## For Chris: how to run a video

Open a session in this folder. Nothing to point at; `CLAUDE.md` sends the
agent to `AGENTS.md`. Your part is five messages:

1. **Start.** "New short: <the idea, or a path to your note>." You get back
   the preflight (the question, who's asking, the one-sentence answer) and
   a storyboard with a read-aloud script, whose first line says the engine
   (Manim or HyperFrames). Edit the script into your words.
2. **Record.** One take in Descript with Studio Sound, pause ~1 s between
   paragraphs. Say "recorded, here's the file and transcript" with the
   `.m4a` path. Everything from cleaning to the first assembled cut
   happens without you.
3. **Iterate.** Watch it on a phone, with sound and muted. Say what's off,
   in your words ("squished", "that example makes no sense"). Each note is
   fixed and the cut re-sent.
4. **Finish.** "Done." You get the hand-off pack: the file path, title,
   description, Substack note. Upload the mp4 natively to Substack; the
   YouTube link goes in the first reply.
5. **Update pass.** When asked "Ready for the update pass?", say go. The
   system absorbs what you asked for this time so the next video starts
   from there.

To work on the system itself rather than a video, open a session and say
so; `AGENTS.md` is the map and `agents/plans/` has what's queued.
