# Episode prompt: build one Classifier Metrics Short

**Name:** classifier-metrics-episode-prompt
**Description:** The prompt Chris pastes into a fresh session to build one
episode of the series, start to hand-off, through the repo's runbook.
**When to use:** one session per episode folder. Replace `FOLDER` with
the folder name (e.g. `ep03-threshold-roc`). Several sessions can run at
once; the prompt keeps them out of each other's files.
**How it works:** the template from `agents/series.md` step 5, with this
series' look, ledger and traps filled in.

---

```text
Build one Short end to end: videos/013-classifier-metrics/FOLDER

Start by reading AGENTS.md (the entry point) and follow agents/runbook.md as the process. Everything you need is in this repo.

Where this episode stands:
- The voice is recorded and cut: FOLDER/vo_raw.m4a. FOLDER/script.md is what I actually said, and its last section lists where the take leaves the planned script (flubs, restarts, lines not said). That transcript, not the planned script, is the VO.
- Runbook steps 0–2 are done. The preflight lines (question, who is asking, one-sentence answer, search phrase) are in FOLDER/idea.md and FOLDER/storyboard.md. FOLDER/storyboard.md is v1, written before the recording: keep its ENGINE line, preflight and visual ideas, and rebuild its beat | VO | visual table on what script.md says. The planned script is in SCRIPTS.md for reference only.

Do, in runbook order:
1. Update FOLDER/storyboard.md (step 1) to the recorded VO: the ENGINE line first, chosen by AGENTS.md "Which engine"; the preflight lines; the ledger from SERIES.md, used identically in every beat; a beat | VO | visual table built from script.md.
2. Clean, transcribe, tighten (steps 3–5). Bring me the cut list and wait for my approval before building beats. Start from the flubs and repeats script.md lists, and flag any others in the take.
3. Render FOLDER/00_layout (the canonical frame) and send it to me; build beats only after I OK the look.
4. Build the beats (step 6) with parallel agents, each briefed with the matching beat brief. Each renders and reviews its own contact sheet. Then check every cut (last frame of beat N beside the first frame of beat N+1).
5. Captions, assembly, review (steps 7–8): sequential clean re-render, assemble, contact sheets, fix what the sheets show. Then tell me the media/short.mp4 path to watch on my phone, and iterate on what I say.
6. Write FOLDER/publish.md (step 9) with a title that starts with the search phrase (SERIES.md "Search phrases"; keep the dead phrases out); description line 1 contains the search phrase. Send the hand-off pack (step 10) when I say done.

This series:
- The two recurring images are in SERIES.md: the score line (dots on a 0 → 1 axis, the threshold as the magenta hero, everything to its right flagged) and the 2×2 box that recounts when the line moves. Real users are teal; attacks get a second accent colour.
- Every number comes from SERIES.md's ledger or _data/ledger.json (generated by _data/make_scores.py, seed 13). Never invent a number in a beat; where the VO rounds ("most of our users"), the visual shows the ledger value.
- Say what the model is (SERIES.md "Context in every episode"): in eps 2–5 the cut list splices ../vo_context_short.m4a (or ../vo_context_long.m4a for ep 2) in right after VO line 1, and frame 0 carries the detector tag on the score line. Ep 1 already says it.
- HyperFrames by default; Manim where a beat needs real plotted axes (the ROC and PR curves).
- Code on screen only where it really belongs (PyTorch first, then sklearn). Don't force it.

Traps:
- Episode folders are one level deeper than a normal videos/NNN-slug/. Manim scene shim: parents[3], not parents[2]. HyperFrames symlinks: ../../../_shared/web/vendor (and any other shared kit). Render from inside FOLDER (or the beat folder, for HyperFrames), never from the repo root, never two renders at once in one folder.
- No LaTeX: Text only.

Other sessions are building other episodes at the same time, so:
- Write only inside FOLDER. Don't edit videos/_shared/, agents/, AGENTS.md, SERIES.md, SCRIPTS.md or _data/. If a part, token or rule should change, list it in your hand-off and I'll take it to the update pass.
- Commit only FOLDER's files (git add with explicit paths), small and often, scenes separate from anything else.
- Finish your hand-off with the SERIES.md checklist line this episode now ticks, and I'll update the checklist.

Skip step 11 (the update pass). It runs once, after all episodes are done.
```
