## Description

What is an agent harness? Everything except the model: context, tools, memory, and the loop.

An agent is the model wearing a harness. Context is what goes into the model this turn: your instructions, the files it opened, the last error. Tools are what it can touch. Memory is what carries over between sessions, like an AGENTS.md. The loop runs the model and the tools, feeds results back, and checks the work.

Same model, different harness: one agent fixes your bug, another goes in circles. When your agent fails, ask which piece was missing.
