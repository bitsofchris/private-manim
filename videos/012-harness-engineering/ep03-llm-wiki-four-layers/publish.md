## Description

An LLM wiki needs four layers: agent notes, a human board, curated rules, and a janitor.

Agents write verbose notes for other agents (hashes, branches, commits) that you never have to read. You read one clean board that links down to those notes when you need them. The skills, rules and conventions live in a curated layer you review with care. And a janitor catches conflicting rules before they spread and clears out old material, so your board stays useful.

Separate what agents write from what you read, and run a janitor.
