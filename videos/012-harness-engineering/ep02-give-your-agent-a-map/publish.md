## Description

Context engineering is giving your agent a map: a short AGENTS.md that points to files.

An agent explores a repo where a person would search. Stuffing every file into the context window backfires (context rot), and one giant AGENTS.md does too: when everything is important, nothing is. A short map in Markdown holds pointers to files, so the agent reads the map and drills into only the one it needs.

Episode 2 of Harness Engineering.
