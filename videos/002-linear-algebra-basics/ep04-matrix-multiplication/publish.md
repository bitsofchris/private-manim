## Description

x @ W is a weighted sum of W's rows: each number in x weights one row, then add the rows.

x = [1, 2, −1] beside a 3 × 2 W, whose rows are where the three input directions land. Each number in x scales its row: one times the first, two times the second, minus one times the third (it flips). Add the weighted rows tip to tail and you get [4, −1]; summing down the columns is the same addition. Add the bias for one row of a linear layer's output, [4.1, −1.2].
